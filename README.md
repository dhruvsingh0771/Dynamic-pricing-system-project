Real-Time Dynamic Pricing & Demand Forecasting Engine

A Python-based backend project that uses machine learning to forecast hourly product demand and recommend optimal prices based on historical data and real-time customer activity.

Tech Stack

Python, FastAPI

Scikit-learn (Poisson Regression)

Pandas, NumPy

SQLite

Key Features

Hourly demand forecasting

Real-time customer event tracking

Dynamic price recommendations

Historical traffic fallback

Price-change guardrails
