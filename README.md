# Dynamic-pricing-system-project
Real-Time Dynamic Pricing & Demand Forecasting
EngineDeveloper: Dhruv Singh
An end-to-end, production-grade intelligent web application that dynamically optimizes product pricing in real time. The architecture integrates live user telemetry streams, machine learning elasticity tracking, and Bayesian inference models within a highly responsive full-stack system.
🧭 Core Course Component Alignment
This project serves as a comprehensive capstone demonstrating the seamless cross-section of five distinct disciplines:
Software Engineering (SE): Built using a completely decoupled multi-tier directory structure, automated regression test assertions via pytest, strict foreign-key database constraints, and normalized transaction boundaries.
Machine Learning (ML): Integrates a scikit-learn predictive optimization pipeline running continuous Linear Regression tracking to calculate historical demand/price elasticity and automate revenue maximization.
Mathematics & Probability (Math): Implements real-time Bayesian Inference equations to constantly update customer purchase conversion likelihood bounds (P(Purchase | Page Views)) based on rolling clickstream data.
Full-Stack Development: Combines a high-performance, asynchronous Python backend API router engine (FastAPI) with a modular, responsive single-page user interface (React/TypeScript/Vite).
Data Visualization (DV): Renders clean, administrative analytics telemetry control dashboards powered by Recharts to plot live pricing trend lines, probability density spreads, and demand forecast curves.
